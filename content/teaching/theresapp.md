At Univerity of Augsburg, every Masters-student in Mathematics must spend some time working on a programming project. Its goal is, that "the Student learns the tools to approach a mathematical problem with the help of a computer".

Kai Cieliebak and I have started to host a project on [the Universities High Performance Computing Cluster](https://www.uni-augsburg.de/en/fakultaet/med/profs/exposure-science/aktuelles/linux-compute-cluster-augsburg/) to offer the students the option to pursue such a programming project mentored by us.

Usually, the projects center around combinatorial geometry problems, with the hope of extending the known literature by a couple of cases.

This Project is one of the [programming projects we hosted so far](tags/progprojs)

## Universal Pointsets

A *universal pointset* of size n is a set of n points in the plane such that every planar graph with n vertices may be embedded into the plane with its vertices onto these points (see [here](https://en.wikipedia.org/wiki/Universal_point_set).

One question is: What is the minimal number k, such that there is no universal pointset of size k.

It was known, that this number is between 11 and 15 [since 2013](https://arxiv.org/pdf/1209.3594).
Then this number was computed [here in 2019](https://arxiv.org/pdf/1811.06482) to be k = 11.

To our knowledge, it is still unknown however, whether for n = 12,13,14 there is a universal pointset of size n.

## The Project

Goal of Theresa Vogls Programming Project was to try to extend the results of the 2019 paper to n=12.
